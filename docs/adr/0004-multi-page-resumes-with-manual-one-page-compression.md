# Multi-Page Resumes with Manual One-Page Compression

A Resume Document may span up to two pages — overflow is not blocked — and a per-document compression control reduces the whole resume in 10% steps, persisted, so any document can be pulled down to a single page when needed. Compression uses layout-aware CSS `zoom` with compensated page dimensions rather than `transform: scale`, because native print pagination must reflow compressed content. The shared renderer is the only print target, and its A4 `@page` rules keep the exported PDF aligned with the preview. We chose manual incremental steps over auto-fit so page geometry stays predictable.
